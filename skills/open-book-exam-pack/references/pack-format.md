# Pack Markdown 格式（build_pdf.py）

`scripts/build_pdf.py` 读取 UTF-8 Markdown 子集，输出 A4 PDF。块之间用空行分隔。

## 语法

| 写法 | 效果 |
| --- | --- |
| `# 标题` | 文档主标题（也作为 PDF 元数据标题） |
| `## 一、章节速查` | 一级小节；剩余空间不足时自动换页，避免标题落在页底 |
| `### 模板 A` | 二级小节 |
| 普通段落 | 连续多行自动合并为一段（中文行间不加空格） |
| `- 条目` / `1. 条目` | 无序 / 有序列表；缩进 2 个空格为下一级 |
| `> 提示` | 浅蓝底提示框，适合“开卷使用法”“易错点” |
| `**加粗**` | 加粗 |
| `==高亮==` | 黄色底高亮；整格写成 `==...==` 时整个单元格变黄 |
| `` `code` `` | 等宽字体（仅 ASCII；含中文时按正文显示） |
| `\| a \| b \|` + `\|---\|---\|` | 表格；第一行是表头，跨页时表头自动重复；单元格内 `\|` 写成 `\\|` |
| `<!-- widths: 20,15,65 -->` | 紧接着的下一张表按百分比分配列宽 |
| `<!-- pagebreak -->` | 强制换页 |
| `<!-- appendix -->` | 换页，用在“计算题专题教程”前 |

不支持图片、脚注、合并单元格和 LaTeX。公式用 Unicode 写（`√`、`×`、`Σ`、`θ`、`²`），复杂矩阵用表格表示。

## 命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-o/--output` | `outputs/<源文件名>.pdf` | 输出路径 |
| `--body-size` | 7.2 | 正文与表格字号（pt）；低于 6.3 会警告 |
| `--title-size` / `--h2-size` | 15 / 10.5 | 标题字号 |
| `--leading` | 1.25 | 行距倍数 |
| `--margin-mm` | 10 | 页边距 |
| `--columns` | 1 | 1-3 栏；2 栏适合紧凑速查 |
| `--landscape` | 关 | 横向 A4 |
| `--no-page-numbers` | 关 | 不印页脚页码 |
| `--font` / `--bold-font` | 自动 | 指定 TrueType 中文字体（.ttf/.ttc）；CFF 格式的 .otf 不支持 |

字体查找顺序：微软雅黑 → 黑体 → 宋体 → macOS 华文黑体 → Linux 文泉驿/文鼎；都找不到时使用 reportlab 内置 `STSong-Light`（不嵌入字体，但所有阅读器都能显示中文）。

## 常用组合

```bash
# 默认：清晰版
python build_pdf.py work/pack.md -o outputs/课程开卷资料_清晰版.pdf

# 紧凑：双栏、小边距
python build_pdf.py work/pack.md -o outputs/课程开卷资料_密集版.pdf --columns 2 --margin-mm 7 --body-size 6.8

# 大字：用户嫌字小
python build_pdf.py work/pack.md -o outputs/课程开卷资料_大字版.pdf --body-size 8.5 --leading 1.3
```
