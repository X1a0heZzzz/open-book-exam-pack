# 通用答题模板

所有模板都要写成考场上能直接抄写的完整句子。先从本课程旧卷里找到该题型的真实题干，再按下列骨架填入本课程内容。

## 内容密度标准

| 分值 | 字数参考 | 必备要素 |
| --- | --- | --- |
| 2-3 分名词解释 | 40-80 字 | 定义 1 句 + 关键特征 1 句 |
| 5 分简答 | 120-200 字 | 定义 1 句 + 机制/区别 2-3 句 + 例子 1 句 + 优缺点/风险 1 句 |
| 8-10 分论述 | 300-500 字 | 观点 + 3 个分论点（各带例子）+ 总结 |
| 10-15 分案例分析 | 400-600 字 | 识别问题 → 对应理论 → 逐条分析 → 对策 → 结论 |
| 计算题 | 不限 | 已知 → 公式 → 代入 → 中间结果 → 结论 + 单位 |

## 1. 概念/定义题

> **<概念>** 是指 <一句话定义>。其核心在于 <机制或关键特征>，与 <相近概念> 的区别是 <区别点>。例如 <课件/教材中的例子>。它的优点是 <优点>，但也存在 <局限>。

## 2. 比较/区别题

先给一句总括，再用表格或“维度 + 对比”的句式：

| 维度 | A | B |
| --- | --- | --- |
| 定义 | | |
| 原理/机制 | | |
| 适用场景 | | |
| 优点 | | |
| 缺点 | | |

> 总之，A 侧重 <…>，B 侧重 <…>；在 <条件> 下应优先选择 <…>。

## 3. 流程/步骤题

> <过程> 主要分为 N 步：① <步骤>：<做什么、为什么>；② …；最后 <输出/结果>。其中关键环节是 <步骤 k>，因为 <原因>。

## 4. 优缺点/评价题

> <对象> 的优势主要体现在：一是 <…>；二是 <…>。不足之处在于：一是 <…>；二是 <…>。因此在 <场景> 中应 <扬长避短的做法>。

## 5. 论述题（观点-展开-总结）

1. 开头：界定核心概念，亮明观点（1-2 句）。
2. 分论点一：<正面作用/理论依据> + 例子。
3. 分论点二：<现实问题/挑战> + 例子。
4. 分论点三：<对策/治理/改进方向> + 例子。
5. 结尾：回扣题干关键词，给出结论或展望。

常见变体（按本课程实际选择）：

- 理工类：原理 → 方法 → 应用 → 局限 → 改进。
- 社科类：背景 → 现状 → 问题 → 原因 → 对策。
- 技术伦理类：贡献 → 挑战 → 治理。
- 法学类：法律关系 → 适用条文 → 分析 → 结论。

## 6. 案例分析题

1. 概括案例：一句话点明案例核心问题。
2. 对应理论：指出涉及的课程理论/模型（带教材页码，便于开卷查原文）。
3. 逐条分析：每条“现象 → 理论解释 → 结论”。
4. 提出对策：针对每个问题给可执行建议。
5. 总结。

## 7. 选择/判断速查

- 按章节列出旧卷原题答案，标注出现年份。
- 总结绝对化表述规律：含“一定、所有、只能、完全、绝不”的判断题多为错误，但必须对照教材原句确认。
- 易混概念对列在一起（如“精确率/召回率”“过拟合/欠拟合”）。

## 8. 计算题教程格式

每种题型一节，固定五段：

1. **题型识别**：题干出现哪些关键词/数据时用这个方法。
2. **公式**：写出完整公式并解释每个符号。
3. **例题**：用旧卷原题或改编题，逐步代入，写出每个中间结果。
4. **易错点**：单位、符号、取整、矩阵维度等。
5. **答题书写模板**：考场上的标准书写顺序。

数字必须自己重算一遍；从扫描卷 OCR 得到的数据要回看截图核对。

## 9. 万能句子库

按本课程的高频话题分组，每组 3-5 句可直接嵌入答案的句子，例如：

- 评价句：“该方法在 <条件> 下效果显著，但对 <因素> 较为敏感。”
- 过渡句：“从 <角度> 来看，……；进一步地，……”
- 结论句：“综上，<对象> 的关键在于 <要点>，未来应在 <方向> 上持续改进。”
