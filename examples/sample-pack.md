## 二、高频简答模板

### 模板 A：概念类（5 分）

1. 定义：用一句话说明它“是什么”。
2. 机制：说明它“怎么做到的”，写 2-3 句。
3. 举例：给出一个具体应用场景。
4. 评价：补一句优点或局限，体现辩证性。

## 附录：计算题专题教程

### 题型 1：余弦相似度

**已知**：向量 `a = (1, 2, 2)`，`b = (2, 0, 1)`。

1. 写公式：cos θ = (a·b) / (|a|·|b|)。
2. 算点积：a·b = 1×2 + 2×0 + 2×1 = 4。
3. 算模长：|a| = √(1+4+4) = 3，|b| = √(4+0+1) = √5 ≈ 2.236。
4. 代入：cos θ = 4 / (3 × 2.236) ≈ ==0.596==。

> 易错点：模长要先平方再开根号；最后结果保留三位小数并写上结论“两向量方向较接近”。
